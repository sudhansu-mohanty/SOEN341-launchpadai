# Sprint 2 Contributions — Ahcene Chouyoukh

**Role:** Developer (Feature 4 Lead: Recruiter Dashboard and Postings, Saved Jobs Drawer, Continuous Integration)

## Summary

Worked on Feature 4 (Recruiter Dashboard and Posting Management) and on the Saved Jobs drawer for job seekers. Also set up the Continuous Integration pipeline for the repository.

**Total time: 14 hours 15 minutes**

## Key Contributions

### Recruiter Dashboard Kickoff View (TASK-2.15): 2 hours
- Built the recruiter dashboard page with a table listing the postings authored by the logged-in recruiter.
- Added the applicant count for each posting in the table.

### Applicant Review Modal (TASK-2.16): 2 hours
- Built the applicant review modal opened from the recruiter dashboard.
- Displayed the candidate list per posting, with a resume viewing action using a signed URL and status badges.

### Saved Jobs / Favorites Drawer (TASK-2.17, US-15): 1 hour
- Added the bookmark toggle on job cards so job seekers can save jobs.
- Built the favorites drawer that lists the saved jobs.

### Continuous Integration Pipeline (CI-2.01 to CI-2.05): 4 hours
- Created the CI workflow (ci.yml) running lint, type check and Vitest tests.
- Fixed the type check step by adding Next.js type references.
- Updated the CI Node version from 20 to 22, as the Supabase packages require 22 or higher.

### Navbar and Create Posting Form: 2 hours
- Updated the navbar so job seeker links are hidden from recruiters, and the My Postings link is shown to recruiters only.
- Built the create posting form on the recruiter dashboard so recruiters can publish new job postings.

### Open/Closed Status, Toggle and Edit Modal (US-06): 1 hour
- Added the Open/Closed status column to the recruiter dashboard table.
- Added the toggle to switch a posting between Open and Closed, and the edit modal to update a posting.
- Showed the recruiter postings in Find Jobs.

### Applicant Names Fix: 15 minutes
- Fixed the applicant names display by adding a profiles policy.

### Applicant Status Dropdown (US-10): 2 hours
- Built the status dropdown so recruiters can update an applicant status (Applied, Interview, Offered, Rejected).
